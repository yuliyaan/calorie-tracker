# Требования: Трекер калорий

## Идея
Приложение для подсчёта суточного потребления калорий. Пользователь идентифицируется через cookies, без авторизации.

## Хранение данных
- Все данные — в cookies браузера (без бэкенда/базы данных)
- Хранится история за последние **30 дней**
- Записи старше 30 дней автоматически удаляются
- Новый день считается по календарной дате устройства пользователя (полночь = начало нового дня)

## Суточная цель
- Пользователь может задать суточную цель по **калориям, КБЖУ и клетчатке**
- Прогресс отображается визуально относительно цели (см. «Визуальный стиль»)

## Ввод записи о еде
Поля формы (все вводятся **вручную**, без автоматического пересчёта под граммовку):
- Название блюда/продукта
- Граммовка
- Калории (ккал)
- Белки (г)
- Жиры (г)
- Углеводы (г)
- Клетчатка (г)

## Управление записями
- Записи можно **редактировать** и **удалять**
- При изменении/удалении записи — итоги дня пересчитываются автоматически

## Логика подсчёта
- Итог за текущий день = сумма ккал/КБЖУ всех записей этого дня
- Итоги отображаются в реальном времени по мере добавления записей

## История за 30 дней
Отображается в **двух видах**:
1. **Список дней с итогами** — каждый день строкой с суммарными ккал/КБЖУ, клик разворачивает список блюд этого дня
2. **Мини-график динамики** — визуализация калорий/КБЖУ по дням за последние 30 дней, отображается сверху над списком

## Визуальный стиль
Референс: **приложение Whoop**
- Тёмная (почти чёрная) цветовая схема
- Круговой (кольцевой) индикатор прогресса по калориям — вместо линейного progress-бара
- Крупная жирная типографика для ключевых цифр
- Карточки статистики с закруглёнными углами на тёмном фоне
- Яркий акцентный цвет (мятно-зелёный) для прогресса и кнопок

## Иконки
- Используются **эмодзи** как визуальные акценты:
  - 🔥 — калории
  - 🥩 — белки
  - 🥑 — жиры
  - 🍞 — углеводы
  - 🌾 — клетчатка
  - 🍽 / ⚖️ — поля формы ввода
